# Технический радар компании «Будущее 2.0»

| Технология / паттерн             | Кольцо   |
|----------------------------------|----------|
| Python                           | `Adopt`  |
| Golang                           | `Adopt`  |
| Java / Spring Boot               | `Adopt`  |
| Terraform                        | `Adopt`  |
| GitHub Actions                   | `Adopt`  |
| Power BI                         | `Adopt`  |
| React                            | `Adopt`  |
| Data Mesh                        | `Trial`  |
| Event-Driven Architecture        | `Trial`  |
| Self-Service BI                  | `Trial`  |
| Domain Data Products             | `Trial`  |
| Yandex Cloud                     | `Trial`  |
| Apache Kafka                     | `Trial`  |
| Schema Registry                  | `Trial`  |
| Apache Flink                     | `Assess` |
| Apache Iceberg / Data Lakehouse  | `Assess` |
| DataHub                          | `Assess` |
| Legacy Anti-Corruption Layer     | `Hold`   |
| PowerBuilder                     | `Hold`   |
| Microsoft SQL Server 2008 DWH    | `Hold`   |
| Apache Camel ESB                 | `Hold`   |

Кольца:
- **Adopt** — рекомендуется к целевому использованию или уже является закрепленной практикой.
- **Trial** — запускать через пилот в одном-двух доменах и масштабировать после проверки ограничений.
- **Assess** — изучить применимость, риски, стоимость или требования к компетенциям.
- **Hold** — не использовать в новых решениях; оставить только на время миграции или до вывода из эксплуатации.
